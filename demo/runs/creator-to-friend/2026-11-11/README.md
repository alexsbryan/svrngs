# Creator to friend: Garden rota

Contract written first: [`demo/creator-to-friend.md`](../../../creator-to-friend.md).
This is a scripted workflow on one Mac, with real svrngs processes, folder
watching, journal admission, the phone signer and browser service worker. Jo's
computer uses Chromium in the current grouped layout B; Kim's hosted page uses
WebKit with an iPhone profile. The folder app is an explicit guide-derived test
fixture, not an artifact secretly attributed to a coding agent or a newcomer.

## Product change

The shared first-open wording now says:

> This app’s shared entries. Opening it lets it read and write only its own
> entries, as you in Garden.

It comes from `home/question.js::agreed`, the actual group and existing app
declaration, on both computer and phone. Reader declarations still say they
cannot write. Opening remains the consent action. The embedded build guide now
explains private testing, copying the finished app, accepting versions and
withdrawing availability without erasing shared history.

The change adds no counted production lines: core **3,506**, non-JavaScript
**21,259**, JavaScript **8,506**. Existing limits and native authority behavior
are exercised by the scene; no Eudoxia production cutover is claimed.

scene's C1-C5 assertions cover:

- A real test entry stays in Jo's private test group when only the finished two
  files are copied into Garden.

homes. The command records retain source hashes and output hashes.

## Human result and product gaps

**Real newcomer session: never-ran.** No result here measures understanding,
onboarding time or success rate. The blind creator/member session is specified
in the contract, separately from browser correctness.

This baseline exposes the next product work: source-backed initial publisher
attribution, a person-facing withdrawal action for folder apps, additional-service
consent, and the explicitly designed private-data-to-group-record handoff.
Removing a folder in a scripted scene is not evidence that a newcomer can find
how to stop sharing through the product.
