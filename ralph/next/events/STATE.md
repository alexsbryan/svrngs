# svrngs events — the primitive event and its reference app (operator, 2026-10-13)

The operator, 2026-10-13: "I want the run after onair to be our event
primitives + reference app (we can layer on this taps concept later)". An
event is a post in a group, and people answer it. There are three acts in
the group's record. Nothing is new in svrngs. Three rows: the app; its
run on one host; the demo that tells it. The decisions are in
`CHARTER.md`; the design is svrn-docs `rings/current/EVENTS.md`.
