This queue fixes what svrn-docs `rings/current/WHAT_CAN_ACT_AS_YOU.md` §6
names: places where code can act as a person beyond what svrngs's own
invariant allows (`WHAT_RUNS_AS_YOU.md` §1: what runs as you is what you or
your group chose to bring, never widened silently). Before a row, read this
queue's `CHARTER.md`, `STATE.md`'s opening, and that note whole.

Fences the rows keep:
1. *Red first, as the protection* (AGENTS.md 2, 5). Each row's first commit
   is a test that the protection holds, failing at HEAD. Describe what is
   refused and why in the test and the commit. A commit body is no place for
   a how-to of what it closes.
2. *Nothing a person does today breaks.* Each fix keeps every legitimate path
   working, and a test names each one it keeps: a person opening a lend from
   their own home page or the group page; a lend's own page moving within
   itself; a phone's yes through the group page; Events' and Money's own
   corrections by their authors.
3. *The decider is one place* (AGENTS.md 8). A check lives where the decision
   already lives: the door's, the fold's, the app's. Never a second copy
   beside it.
4. *Glassbox* (AGENTS.md 1). Every refusal traces at debug and names the fact
   that refused it. The person is told in words they can act on.
5. *The budget:* the economizing pass first, and a raise is the operator's.
   `apps/` is not counted.
6. *The trust floor* (`scripts/trust_floor.txt`) is only ever narrowed here.
   A widening is NEEDS_HUMAN.md.
7. *Publishing is the operator's.* The last row prepares a release and stops.
