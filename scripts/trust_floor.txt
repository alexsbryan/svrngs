# The trust floor (svrn-docs rings/current/WHAT_RUNS_AS_YOU.md §1, §4): the one
# home for what svrngs lets a page or a socket do. What runs as you, and what
# can reach you, is what you or your group chose to bring; svrngs never widens
# it silently. scripts/trust_check.py, in scripts/check.sh, holds the code to
# this file, and this file to its history: a commit that changes it says why
# on a line of its body, `Trust floor: <the reason, and what was tried first>`.
# Changing it is the operator's, as a size-budget raise is (AGENTS.md "Done").
#
# page <name> <file> <anchor>: the policy that file serves, the one string
#   literal after the anchor, which the file holds once. Under it, each
#   directive as served, token by token, in any order. Anything past 'self'
#   or 'none' is a widening, and gives its reason after ` | `.
# listen <file>: <the line> | <the address, and why>: each place svrngs binds
#   a socket, the line as its code reads, trimmed. A line that binds and is
#   not here fails the gate; so does one here that is gone.
# gate <file> <test> | <what it holds>: a behavioural gate, a test cargo runs
#   in check.sh. Taking it out, renaming it or ignoring it is a widening.

# A carried app's every answer (crates/svrngs-node/src/carried.rs, `FLOOR`):
# code from its own files alone, and nothing loaded from elsewhere
# (COMMUNITY_APPS §6.2). Never 'wasm-unsafe-eval': canon runs here as plain
# JavaScript, built through wasm2js (ralph/next/canon/CHARTER.md).
page carried crates/svrngs-node/src/carried.rs const POLICY: &str =
  default-src 'self'
  script-src 'self'
  style-src 'self' 'unsafe-inline' | an app's own styles, in its page; its scripts are untouched
  img-src 'self' data: | an app's own images written into its page as a data URL; an image runs nothing
  connect-src 'self'
  object-src 'none'
  base-uri 'none'
  form-action 'self'
  frame-src 'self'
  worker-src 'self'
page carried-permissions crates/svrngs-node/src/carried.rs "permissions-policy",
  camera=()
  microphone=()
  geolocation=()
page carried-prefetch crates/svrngs-node/src/carried.rs "x-dns-prefetch-control",
  off

# The home page (crates/svrngs-node/src/home.rs, `only_itself`): no widening.
page home crates/svrngs-node/src/home.rs const POLICY: &str =
  default-src 'self'
  frame-ancestors 'none'
